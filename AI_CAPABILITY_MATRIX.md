# MATRIZ DE CAPACIDADES DE INTELIGENCIA ARTIFICIAL (AI CAPABILITY MATRIX)
## SALTBOR PHASE 1.15 — CAPA DE INTELIGENCIA MODULAR Y ASISTIDA

| Dimensión | Proveedor Local (Ollama) | Proveedor Remoto (OpenAI / Gemini) | Proveedor Heurístico Offline (SALTBOR Native) | Regla de Enrutamiento SALTBOR |
| :--- | :--- | :--- | :--- | :--- |
| **Parsing de Lenguaje Natural a Escenario** | Modelos 7B-14B (Llama 3.2, Mistral) con JSON estructurado. | GPT-4o / Gemini 1.5 Pro con Structured Outputs / Pydantic. | Extractor semántico determinista basado en reglas gramaticales y diccionario salvadoreño. | **Prioridad**: Remoto (si autorizado y con clave) $\rightarrow$ Local Ollama (si activo) $\rightarrow$ Heurístico Nativo (offline default). |
| **Extracción de Parámetros Geográficos** | Búsqueda por entidades nombradas (NER) local. | Extracción multivariable con alta tolerancia léxica. | Búsqueda exacta y aproximada en `territory_data.py` (D.L. 762). | **Nativo Obligatorio**: Todo nombre de cantón/municipio debe validarse contra el dataset oficial de El Salvador. |
| **Proposición de Mecanismos Causales** | Sugerencia basada en prompt contextual. | Razonamiento causal extendido con cot / system prompts. | Matriz precalibrada de mecanismos (`CAUSAL_MECHANISM_REGISTRY`). | **Validación Requerida**: Ninguna IA puede inventar deltas numéricos. Si no está en el catálogo, se clasifica como `HYPOTHESIS_PENDING_VALIDATION`. |
| **Análisis e Interpretación de Resultados** | Generación de resúmenes textuales de indicadores. | Informes comparativos y narrativas multidominio. | Generador de reportes de variaciones porcentuales y deltas del ledger contable. | **Heurístico + IA**: Solo se emiten afirmaciones soportadas por el historial de ticks o el ledger contable. |
| **Cálculos Numéricos y Fricción Espacial** | NO PERMITIDO. | NO PERMITIDO. | Motores Nativos (`CrossDomainInteractionEngine`, Haversine). | **100% Nativo**: La IA nunca calcula ticks, fricciones, balances ni colas $M/M/c$. |
| **Actualización de Estados de Humanos Sintéticos** | NO PERMITIDO. | NO PERMITIDO. | Motores Nativos (`HumanBehaviorHeterogeneityEngine`). | **100% Nativo**: La IA jamás modifica billeteras, inventarios o estados de salud directamente. |
| **Disponibilidad y Conectividad** | Requiere daemon local en puerto 11434. | Requiere Internet y clave de API válida. | 100% disponible, cero dependencias, ejecución < 1 ms. | El sistema nunca falla por desconexión; conmuta de forma transparente al proveedor nativo. |
| **Costo Computacional y Financiero** | Cero costo monetario; consume CPU/GPU local. | Requiere tokens de pago o cuota de API. | Cero costo monetario; impacto de memoria despreciable (< 2 MB). | El usuario define presupuestos de tokens; el proveedor nativo maneja fallbacks automáticos. |
| **Privacidad de Datos Individuales** | 100% local; sin exfiltración de datos. | Potencial riesgo si se envían identificadores personales. | 100% local; sin exfiltración. | Principio de minimización: Solo se envían agregados o descripciones abstractas; nunca identificadores directos. |
